# 로고

- `logo/text_logo6.png`: 지금 쓰는 메인 로고 원본(2048×2048, 흰 바탕, T와 오르는 화살표).
- `logo/logo.jpg`, `logo/text_logo1~5.png`, `logo/compass_logo1~5`: 예전·예비 로고 원본.

사이트에 쓰는 파일은 원본에서 만들어 `public/`에 둔다. 흰 바탕 원본은 어두운 화면에서 사각형으로 보이므로, 그림 둘레에 맞춰 정사각형으로 자르고(여백 4%, 로고 파일 기준. 파비콘은 여백 20%) 흰 바탕을 투명하게 한다(모서리에서 이어진 흰색만 지우므로 그림 안의 색은 그대로).

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `public/logo.png` | 256×256 | 메인 화면 제목 위 |
| `public/favicon.ico` | 16·32·48, 투명, 둘레 여백 20% | 브라우저 탭, 구글 검색 결과 |
| `public/favicon-48.png`, `favicon-96.png`, `favicon.png`(96) | 48·96·96, 투명, 둘레 여백 20% | 브라우저 탭, 구글 검색 결과(48의 배수 권장, 원형으로 잘려 여백이 필요) |
| `public/apple-touch-icon.png` | 180×180, 흰 바탕 사각형 | iOS 홈 화면 |
| `public/icon-192.png` | 192×192 | 링크 미리보기(`og:image`) |

로고를 바꾸면 원본을 넣고 위 파일들을 다시 만든다.
