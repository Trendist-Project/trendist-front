# Trendist 토스 미니앱(앱인토스) 출시 기록

토스 미니앱으로 내기 위해 정한 것과 콘솔에 넣은 값을 모아 둔다. 빌드 방법은 [README.md](README.md), 기술 설명은 백엔드 저장소 `docs/2-tech.md` 12절.

## 1. 구조

- 이 폴더(`toss/`)가 토스용 빌드다. 게임 코드는 상위 `src`를 그대로 쓰고, `.env.*`의 `VITE_PLATFORM=toss`로 토스 모드를 켠다(`src/platform.ts`).
- `npm run build` → `vite build`(게임만, 관리자 페이지 제외) → `ait build` → `trendist.ait`. 이 파일을 콘솔 [앱 번들]에 올린다. `.ait`는 git에 넣지 않는다.
- 백엔드는 운영 서버 그대로(`https://trendist.kr`, `.env.production`의 `VITE_API_BASE`). 백엔드 코드는 바꾸지 않았다.
- 앱인토스 CLI는 Node 20 이상이 필요하다. 이 PC는 Node 18이라 개발 의존성 `node@22`를 두었고 `npm run`이 그 Node를 쓴다.
- `apps-in-toss.config.ts`: `appName: 'trendist'`(콘솔 앱 이름과 같아야 업로드됨), 브랜드 색 `#3fb68b`, 클립보드 쓰기 권한(자랑하기 카드 링크 복사), 당겨서 새로고침·뒤로 가기 제스처·화면 튕김 끔(조이스틱 조작 보호).

## 2. 토스에서 달라지는 점

| 항목 | 웹 | 토스 |
|---|---|---|
| 로그인 | 게스트 또는 구글 | 게스트만. 구글 로그인 버튼을 숨김(구글이 앱 웹뷰 로그인을 막음) |
| 기록 이어 가기 | 방문자 ID·갱신 토큰 쿠키 | 안 됨. 쿠키(`SameSite=Lax`)가 다른 출처라 오가지 않아 실행할 때마다 새 게스트 |
| 플레이 기록 저장 | DB 저장 | 한 번 실행하는 동안은 그 게스트로 DB에 저장(재실행하면 찾아갈 수 없음) |
| 로그인 전용 기능(이동 효과, 이미지 업로드 등) | 로그인하면 사용 | 미리 보기만 |
| 카카오톡 공유 | 키가 있으면 보임 | 키를 넣지 않아 숨김 |
| 관리자 페이지 | `/admin/` | 빌드에 넣지 않음 |

나중에 할 일: 기록 이어 가기(토큰을 쿠키 대신 응답 본문·저장소로 주고받거나 토스 로그인 연동). 둘 다 백엔드 수정이 필요하다. 그 전까지는 쓰고 버려지는 게스트 행이 쌓인다.

## 3. 운영 서버 설정(코드 아님)

토스 미니앱은 다른 출처에서 열리므로 서버가 그 출처를 허용해야 한다(앱인토스 공지, SDK 3.1.1 이상 기준).

| Origin | 용도 |
|---|---|
| `https://trendist.apps.tossmini.com` | 실제 서비스 |
| `https://trendist.private-apps.tossmini.com` | 콘솔 QR 테스트 |
| `https://trendist.web.tossmini.com`, `https://trendist.private-web.tossmini.com` | SDK 3.x 예전 Origin(제거하라는 안내가 없어 같이 허용) |

- WebSocket: 서버 `.env`(GitHub 시크릿 `ENV_FILE`)의 `PROD_ALLOWED_ORIGINS`. 지정하면 기본값을 덮어쓰므로 기존 주소도 같이 넣는다.
  ```
  PROD_ALLOWED_ORIGINS=https://trendist.kr,https://www.trendist.kr,https://trendist.apps.tossmini.com,https://trendist.private-apps.tossmini.com,https://trendist.web.tossmini.com,https://trendist.private-web.tossmini.com
  ```
- HTTP: nginx `/api`, `/share/`에 위 토스 출처의 CORS 헤더(쿠키 없이, `OPTIONS` 응답 포함).
- `trendist` 부분은 콘솔 앱 이름(`appName`)이다. 바뀌면 같이 바꾼다.

참고: [SDK 3.x Origin 변경에 따른 CORS 설정 안내](https://techchat-apps-in-toss.toss.im/t/sdk-3-x-origin-cors/4655), [WebView 미니앱의 Storage와 CORS 설정](https://techchat-apps-in-toss.toss.im/t/webview-storage-cors/4673)

## 4. 콘솔 입력값

### 번들 정보

- 앱 번들: `toss/trendist.ait`
- 메모: `v0.1.0 첫 출시 번들 (한국 서버 단일 방, 한국어 UI, 게스트 전용)`
- 출시 노트:

```
실시간 유행 키워드로 내 원을 키우는 멀티플레이 아레나 게임입니다.

[주요 화면]
1. 메인 화면: 게임 소개와 [시작] 버튼. 처음 오면 닉네임을 정하고 바로 입장합니다.
2. 게임 화면(아레나): 다른 플레이어의 원이 함께 움직이는 실시간 아레나입니다. 화면을 누른 채 끌면 조이스틱으로 이동합니다.
3. 검색·보관함(하단 시트): 키워드를 검색해 트렌드 점수를 확인하고 [+]로 보관함에 담습니다. 담은 키워드는 24시간 유지됩니다.
4. 내 정보(☰ 메뉴): 레벨, 칭호, 원 꾸미기, 기록, 자랑하기 카드를 볼 수 있습니다.

[주요 기능]
- 키워드 +: 지금 뜨는 키워드일수록 점수가 높고, 점수만큼 원이 커집니다.
- 충돌: 원끼리 부딪히면 점수가 낮은 쪽이 키워드 1개를 잃고 이긴 쪽이 가져갑니다. 잃은 직후 3초 무적, 세이프존은 안전합니다.
- ? 구슬·트렌드 상자: 아레나를 돌아다니며 먹거나 열면 키워드를 얻거나 힌트를 봅니다.
- 리더보드·미니맵·채팅·키워드 댓글, 칭호와 레벨 성장.
- 채팅·댓글은 신고 기능이 있고, 링크·전화번호는 자동 차단됩니다.

[테스트 방법]
[시작] → 닉네임 입력 → 입장 → 하단 [🔍 검색]에서 아무 키워드나 검색 → [+] → 원이 커지는 것을 확인해 주세요.
접속자가 적을 때는 봇이 함께 플레이합니다.
```

### 기본 정보

| 항목 | 값 |
|---|---|
| 한국어 앱 이름 | 트렌디스트 (영문으로 둘 경우 `Trendist`) |
| 영어 앱 이름 | `Trendist` (각 단어 첫 글자 대문자 규칙) |
| 부제(20자 이내) | `뜨는 키워드로 내 원을 키우는 게임` (19자) |
| 카테고리 | 게임 > 액션 |

부제 다른 안: `유행을 먼저 찾으면 커지는 게임`(17자), `유행을 아는 자, 커진다.`(14자)

카테고리: 실시간으로 움직이며 다른 플레이어와 부딪혀 키워드를 빼앗는 .io 아레나라서 **액션**이 맞다. 퍼즐(정답 풀이)·RPG(캐릭터 육성·스토리 중심)·전략(턴·자원 운영)과는 핵심 조작이 다르다. 목록에 캐주얼·멀티플레이 같은 항목이 있으면 그쪽도 후보.

### 상세 설명

```
유행을 아는 자, 커진다.

요즘 유행은 2주면 끝나요. 남들보다 먼저 뜨는 키워드를 찾아 +하고, 내 원을 키워 보세요.

■ 이렇게 플레이해요
🔍 키워드 찾기: 요즘 뜬다 싶은 키워드를 검색하면 지금의 트렌드 점수를 보여 줘요.
➕ 먼저 +하기: +한 키워드는 24시간 동안 내 보관함에 남고, 점수만큼 내 원이 커져요.
⭕ 부딪혀 이기기: 큰 원이 작은 원을 튕겨내요. 지면 키워드 1개를 잃고, 이기면 상대 키워드를 빼앗아요.

■ 이런 재미가 있어요
- 24시간 쉬지 않는 실시간 아레나에서 전국의 플레이어와 겨뤄요.
- 실제 인기 검색어와 함께 움직이는 점수라서 매일 새로운 판이 열려요.
- 급상승 순위는 공개하지 않아요. 내 안목으로 먼저 찾는 사람이 이겨요.
- 아레나의 ? 구슬과 트렌드 상자에서 숨은 키워드를 얻어요.
- 레벨을 올려 거북이 캐릭터를 키우고, 칭호와 원 꾸미기를 모아 보세요.
- 리더보드에 오르고, 내 기록을 자랑하기 카드로 친구에게 공유해요.

🕹 화면을 누른 채 끌면 조이스틱으로 움직여요.
🛡 키워드를 잃으면 3초 무적, 세이프존 안은 안전해요.
```

### 썸네일·스크린샷

원본은 `image/`, 콘솔에 올릴 파일은 `image/upload/`. 다시 만들려면 `python3 fit_images.py image image/upload`(Pillow 필요).

| 콘솔 항목 | 규격 | 파일 | 원본 | 맞춘 방법 |
|---|---|---|---|---|
| 썸네일 | 1932×828 | `thumbnail_1932x828.png` | 썸네일.png (1892×779) | 높이에 맞춰 확대, 좌우 배경만 잘라 냄 |
| 가로형 | 1504×741 (최소 1장) | `landscape_1504x741.png` | 가로형.png (1908×858) | 폭에 맞춰 축소, 아래 65px를 바닥 격자로 채움 |
