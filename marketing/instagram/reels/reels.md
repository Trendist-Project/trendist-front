방향: **"유행"이 아니라 "지금 터지는 이슈·트렌드 키워드를 먼저 찾는 사람이 커진다"** 로 통일했다. 이슈별 수명 같은 근거 없는 수치는 쓰지 않고, 게임 규칙(키워드 `+`, 보유자 3명이면 활성, 보유자가 늘수록 점수↑, 큰 쪽이 이김, 레벨 구간 색, Lv.100 무지개)만 보여 준다.

## 음악·글꼴 라이선스
- **BGM(3편 공통): `bgm-heartbeat.mp3`** — 어두운 서스펜스 스릴러 곡(E minor, 116bpm, 18.6초). 심장박동 킥 위에 E음이 깔리고 트레몰로 현·낮은 피아노가 얹히며 도미넌트(B)로 조였다가 풀리고, 엔딩 히트(16.5초)가 마지막 안내 화면과 맞물린다. `_src/reels/music/compose.py`의 곡 `B`로 직접 작곡·연주·믹싱했다. 다른 후보 곡은 `bgm-options/`에 있다.
- 연주 소리는 **GeneralUser GS 사운드폰트**의 악기 샘플이다. 라이선스는 "개인·상업 음악 제작에 제한 없이 사용 가능"(`_src/reels/music/SOUNDFONT-LICENSE.txt`)이다. 다만 작성자가 일부 샘플의 출처를 100% 확신하지 못한다고 적어 두었다(지금까지 문제 제기는 없었다고 한다).
- 효과음(타격·`+`·레벨업 등)은 `_src/reels/audio.py`가 직접 합성한 낮고 부드러운 소리다(3kHz 이하).
- 글꼴 Noto Sans KR·Symbols 2: SIL OFL 1.1 / 이모지 Twemoji: CC-BY 4.0(캡션에 출처 표기) / 로고·거북이: 서비스 자산.
- 인스타 라이브러리 음원을 따로 얹고 싶으면 업로드 화면에서 영상 소리를 끄고 고른다.

## 다시 만들기
```bash
cd trendist-front/marketing/instagram/_src
npm install                                   # 처음 한 번
FFMPEG=<libx264·aac가 들어 있는 ffmpeg 경로> node reels.mjs            # 3편 모두 (약 3분)
FFMPEG=... node reels.mjs reel2                                       # 한 편만
ONLY_T=9.0 node reels.mjs reel1                                       # 9.0초 장면 한 장만 ../reels/_still-*.png로 확인
```
- 자막·장면은 `_src/reels/reelN.js`(시간 t로 한 프레임을 그리는 `draw`, 자막 `caps`, 효과음 시점 `cues`). BGM은 `reels/bgm-heartbeat.mp3`를 그대로 쓰고, 효과음만 `audio.py`가 만들어 `reels.mjs`가 ffmpeg로 섞는다.
- 충격파·갈고리 같은 스킬 그림은 게임의 `src/game/skillFx.ts`를 묶은 `_src/game.bundle.js`로 그린다. 게임 연출이 바뀌면 번들을 다시 만든다(`_src/README.md`).
- 곡을 새로 만들거나 고칠 때: `pip install tinysoundfont pedalboard numpy` 후 `SF2=<GeneralUser-GS.sf2 경로> python3 _src/reels/music/compose.py B out.wav` (곡 설정은 `compose.py`의 `SONGS`). 결과를 mp3로 변환해 `bgm-heartbeat.mp3`를 교체한다.
- ffmpeg: 시스템에 없으면 `npm i ffmpeg-static`(임시 폴더)로 받는다. Playwright가 가진 ffmpeg는 H.264를 못 만든다.
- 크로미엄은 `~/.cache/ms-playwright/chromium-1134`를 쓰고, 없으면 Playwright 기본 경로를 쓴다.
