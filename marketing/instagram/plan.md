## 1. 상황 분석

### 1-1. 서비스가 가진 무기
- **한 문장으로 설명되는 규칙**: 뜨는 키워드를 찾아 `+` → 원이 커짐 → 부딪히면 큰 쪽이 이김. (설명 3초, 이해 10초)
- **"먼저 알았다"는 자랑 욕구**를 건드리는 소재. 유행 키워드 자체가 매일 바뀌어 콘텐츠가 낡지 않는다.
- **진입 장벽이 낮다**: 설치 없음, 게스트로 바로 시작, PC·모바일 모두 가능.
- **귀엽고 공유하기 좋은 성장 요소**: 레벨이 오를수록 자라는 거북이(1~10레벨 완성, 11레벨부터 색이 바뀌고 100레벨은 무지개), 칭호, 자랑하기 카드.
- **볼거리가 있는 전투**: 스킬 8종(대시·방패·갈고리·충격파·은신·암흑·독·정화)과 각각의 연출이 있어 릴스 소재로 좋다.

### 1-2. 약점(숨기지 말고 기획에 반영)
| 약점 | 영향 | 대응 |
|---|---|---|
| 접속자가 적으면 아레나가 비어 보임(캡처 때 3명 접속, 아레나 중앙에 내 원 하나) | 첫인상이 "재미없어 보임" → 이탈 | **동시 접속 시간대를 정해 모으기**(8절 "트렌디스트 나이트") + 봇 수·분포 점검 |
| 첫 화면의 "이렇게 놀아요" 팝업이 길다(스크롤이 필요한 글 덩어리) | 인스타 유입자는 30초 안에 재미를 못 느끼면 이탈 | 10절 온보딩 개선 제안 |
| 인지도 0, 팔로워 0 가정 | 피드 도달이 제한적 | 저장·공유 유도형 콘텐츠 + 시딩(8절) |
| 데이터 출처(구글 트렌드)의 이용 조건 | 광고·상업적 사용 시 이슈 가능 | 11절 리스크 |

### 1-3. 인사이트(소비자의 마음)
1. "이거 먼저 알았는데…" — **FOMO와 인정욕구**가 동시에 있다.
2. 유행이 너무 빨라서 따라가기 피곤하다 → **게임으로 가볍게 소비**하고 싶다.
3. 귀여운 캐릭터를 키우는 것은 **저장·공유·재방문**을 만든다.

## 2. 포지셔닝과 메시지

**포지셔닝**: "유행 감각을 겨루는 .io 게임" — 트렌드 뉴스 앱이 아니라 *놀면서 증명하는* 게임.

**슬로건(서비스 문구 그대로)**: 트랜드를 아는 자, 커진다.

| 메시지 기둥 | 한 줄 카피 | 쓰는 곳 |
|---|---|---|
| ① 먼저 (FOMO) | 유행, 누가 먼저 알았을까? | 피드 1 표지, 퀴즈 |
| ② 커진다 (성장) | 찾고 + 하면 내 원이 커져요 | 피드 1 3장, 거북이 |
| ③ 부딪힌다 (경쟁) | 커지면 부딪힐 때 이겨요 | 피드 1 4장, 스킬 |
| ④ 귀엽다 (애착) | 내 거북이, 얼마나 컸을까? | 피드 2 |

**톤앤매너**: 가볍고 약간 도발적. 반말 아닌 해요체. 이모지는 포인트로만. "대박/미쳤다" 같은 과장 표현은 피한다(신뢰).

## 3. 목표와 지표(KPI)

> 아래 숫자는 **가정치**다. 계정의 현재 팔로워·과거 데이터가 없어 업계 평균을 기준으로 잡지 않았다. 1주 차 결과로 기준선을 만든 뒤 2주 차부터 보정한다.

| 단계 | 지표 | 어디서 보나 | 1주 차에 볼 것 |
|---|---|---|---|
| 도달 | 도달 계정 수, 비팔로워 비율 | 인스타 인사이트 | 비팔로워 비율이 높은 포맷은? (릴스 vs 캐러셀) |
| 관심 | **저장 수, 공유 수**, 캐러셀 마지막 장 도달률 | 인사이트 | 저장+공유가 좋아요보다 중요(알고리즘 가중) |
| 이동 | 프로필 방문, **링크 클릭** | 인사이트, UTM | 게시물별 클릭 비교 |
| 전환 | 게스트 세션 시작, 키워드 첫 `+` 달성률 | 서비스의 GTM/GA | 첫 `+`까지 걸리는 시간 |
| 유지 | D1·D7 재방문 | GA | 거북이 Lv.2 도달, 칭호 획득 여부 |
| 참여 | #내원키우기 게시물 수, 댓글 수 | 해시태그 검색 | 사용자 생성 콘텐츠 첫 발생 시점 |

링크 UTM 규칙(피드마다 다르게):
```
https://trendist.kr/?utm_source=instagram&utm_medium=feed&utm_campaign=launch_f1     ← 피드 1
https://trendist.kr/?utm_source=instagram&utm_medium=feed&utm_campaign=turtle_f2     ← 피드 2
https://trendist.kr/?utm_source=instagram&utm_medium=feed&utm_campaign=skills_f3     ← 피드 3
https://trendist.kr/?utm_source=instagram&utm_medium=story&utm_campaign=night        ← 스토리(나이트)
https://trendist.kr/?utm_source=instagram&utm_medium=reels&utm_campaign=reels_hook   ← 릴스
```
이미지 QR은 `launch` 캠페인 값으로 만들었다. 피드마다 QR을 따로 추적하려면 `_src/qr.svg`를 다시 만들면 된다.

## 4. 포맷 규칙(모든 피드 공통)

- **4:5 세로(1080×1350) 캐러셀**. 프로필 격자에서 위아래가 잘릴 수 있어 핵심 문구는 가운데 영역에 둔다.
- **1장 = 훅(질문·숫자)**, **마지막 장 = 행동 유도(QR·링크·댓글)**.
- 장당 문장은 짧게(제목 2줄 이내). 폰에서 한 번에 읽혀야 한다.
- 브랜드 컬러: 어두운 남색 바탕 + 초록(`#3fb68b`) 포인트. 게임 화면과 같은 색이라 클릭 후 이질감이 없다.
- 거북이·스킬 연출은 **게임의 실제 그리기 코드로 만든 그림**이다(게임에서 보이는 모양 그대로).
- 모든 캡션 첫 줄은 훅, 둘째 줄 이후는 혜택, 끝에 행동 한 가지(링크 또는 댓글).

## 5. 4주 운영 캘린더

> 게시 시간은 **가정**이다(한국 사용자 기준 평일 저녁·주말 낮이 일반적). 1주 차에 시간대를 바꿔 비교(A/B)해 보고 인사이트의 "팔로워가 가장 활발한 시간"으로 맞춘다.

|---|---|---|---|---|
| **1주(런칭)** | 목 20:00 | 피드(캐러셀 7) | **피드 1 런칭** | 서비스 첫 소개 |
| | 목 20:30 | 스토리 | 피드 1 공유 + "오늘 밤 9시 접속 모여라" 카운트다운 | 동시 접속 만들기 |
| | 목 21:00~22:00 | 스토리 | 라이브 플레이 화면 녹화 올리기 / 질문 스티커 | 첫 접속자 반응 |
| | 토 11:00 | 피드(1장) | **피드 4 촉 테스트(퀴즈)** | 댓글·참여 |
| | 일 20:00 | 릴스 | **릴스 ①** 갈고리 15초 | 비팔로워 도달 |
| **2주** | 화 20:00 | 피드(캐러셀 4) | **피드 2 거북이 성장** | 저장·공유 |
| | 목 20:00 | 스토리 | 퀴즈 정답 + 투표 스티커("나는 거북이 몇 레벨?") | 참여 |
| | 토 12:00 | 릴스 | **릴스 ②** 거북이 Lv.1→10 타임랩스 | 도달 |
| **3주** | 화 20:00 | 피드(캐러셀 4) | **피드 3 스킬 8종** | 게임 재미 전달 |
| | 목 21:00 | 스토리 | 트렌디스트 나이트 2회차(스킬 대결) | 동시 접속 |
| | 일 20:00 | 릴스 | **릴스 ③** "유행 몇 일 갔게?" | 퀴즈형 릴스 |

## 10. 전환율을 위해 광고 전에 확인할 것 (제품 쪽 제안)

캡처 과정에서 확인한 내용이다. **홍보 전에 하면 전환이 크게 달라질 수 있다.**

1. **첫 화면 안내 팝업이 길다**: "이렇게 놀아요" 팝업이 스크롤이 필요한 글 덩어리다. 인스타 유입자는 대부분 모바일·짧은 집중이다 → **3줄 이내 + 큰 [시작] 버튼**으로 줄이거나, 첫 방문에는 *단계별 말풍선 3개*로 바꾸는 것을 권한다.
2. **빈 아레나**: 접속자가 적으면 내 원 혼자 덩그러니 있다(캡처 시 접속 3명). 홍보 시간대에는 봇 밀도를 높이고, 첫 입장 때 가까운 곳에 구슬·봇이 보이게 하는 것을 권한다.
3. **첫 `+`까지의 시간**: 검색창에 무엇을 넣어야 할지 모르는 사람을 위해 *오늘의 예시 키워드 칩*(또는 랜덤 추천) 한 줄이 있으면 첫 성공 경험이 빨라진다.
4. **동시 접속 한계 확인**: 런칭 스토리에서 접속이 몰릴 수 있다. 서버·DB 부하는 사전에 점검한다(스토리 카운트다운 때 특히).
5. **GTM/GA 이벤트**: 게스트 시작·첫 `+`·레벨업 이벤트가 있는지 확인해 UTM과 연결한다.
6. **프로필 링크 한 개로 통일**: 링크 모음 서비스 없이 `https://trendist.kr/?utm_source=instagram&utm_medium=profile`로 직접 연결.
